# Пять тест-кейсов магазина SauceDemo

Во всех сценариях используется [SauceDemo](https://www.saucedemo.com/) в Chromium. Пароль для демопрофилей указан на странице входа.

## TC-01. Вход стандартным профилем

**Предусловие.** Открыта форма входа, пользователь вышел из системы.

1. Ввести `standard_user` в поле Username.
2. Ввести общий пароль демопрофилей в поле Password.
3. Нажать Login.

**Ожидаемо.** Открывается `/inventory.html` с каталогом Products.

**Фактически.** Открылся каталог Products, в нём шесть карточек. Тест пройден.

## TC-02. Сортировка цен по возрастанию

**Предусловие.** Выполнен вход стандартным профилем, открыт каталог.

1. Открыть список Sort products.
2. Выбрать Price (low to high).
3. Считать цены сверху вниз.

**Ожидаемо.** Каждая следующая цена больше либо равна предыдущей.

**Фактически.** Отображены 7.99, 9.99, 15.99, 15.99, 29.99, 49.99 USD. Тест пройден.

## TC-03. Добавление товара в корзину

**Предусловие.** Пользователь `standard_user` открыл каталог, корзина пуста.

1. На карточке Sauce Labs Onesie нажать Add to cart.
2. Проверить счётчик корзины и открыть корзину.
3. Сверить наименование, количество и цену.

**Ожидаемо.** Счётчик равен 1, в корзине одна строка Sauce Labs Onesie с количеством 1 и ценой 7.99 USD.

**Фактически.** Появился счётчик 1. В корзине одна позиция Sauce Labs Onesie по цене 7.99 USD, количество 1. Тест пройден.

## TC-04. Удаление последнего товара

**Предусловие.** Открыта корзина с одной позицией Sauce Labs Onesie.

1. Нажать Remove напротив позиции.
2. Проверить список и индикатор корзины.

**Ожидаемо.** Позиция исчезает, индикатор количества очищается, корзина остаётся открытой.

**Фактически.** Строка товара исчезла, в шапке отображалась пустая корзина. Тест пройден.

## TC-05. Изображения каталога в профиле problem_user

**Предусловие.** Пользователь вышел из системы, доступен демопрофиль `problem_user`.

1. Войти как `problem_user` с общим паролем демопрофилей.
2. Сравнить фотографии Backpack, Bike Light и других карточек.
3. Сравнить результат с каталогом `standard_user`.

**Ожидаемо.** У каждой карточки изображён её товар.

**Фактически.** Все шесть карточек используют одно изображение. Тест не пройден, зарегистрирован [SD-01](bug-report.md).
