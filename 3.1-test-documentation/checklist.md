# Практическая работа 3.1. Чек-лист магазина SauceDemo

Проверка выполнена 9 ноября 2026 года в Chromium на [учебном магазине SauceDemo](https://www.saucedemo.com/). Для стандартных проверок использован опубликованный на странице демопрофиль `standard_user`. Каждый сценарий начинается с пустой корзины, если не указано иное.

| № | Проверка | Ожидаемый результат | Фактический результат | Итог |
|---|---|---|---|---|
| CH-01 | Вход стандартным профилем | Открывается каталог | Открылся каталог из шести товаров | Пройдено |
| CH-02 | Изображения стандартного каталога | У каждого товара собственное фото | У шести карточек разные файлы изображений | Пройдено |
| CH-03 | Сортировка Price (low to high) | Цены идут по возрастанию | 7.99, 9.99, 15.99, 15.99, 29.99, 49.99 USD | Пройдено |
| CH-04 | Добавление одного товара в пустую корзину | Счётчик становится равен 1, в корзине виден этот товар | Счётчик показал 1, в корзине появилась Sauce Labs Onesie | Пройдено |
| CH-05 | Удаление последнего товара из корзины | Строка товара исчезает, счётчик очищается | Корзина стала пустой | Пройдено |
| CH-06 | Выход через меню Logout | Появляется форма входа | После выхода открылась форма входа | Пройдено |
| CH-07 | Изображения каталога для `problem_user` | Изображения соответствуют названиям товаров | Все шесть карточек показывают один и тот же файл | Дефект SD-01 |
| CH-08 | Отправка пустой формы входа | Вход отклоняется, показано сообщение об обязательном поле | Показано `Username is required` | Пройдено |

Подробные сценарии приведены в [тест-кейсах](test-cases.md). Несоответствие CH-07 описано в [баг-репорте SD-01](bug-report.md).
